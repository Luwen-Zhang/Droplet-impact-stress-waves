The data and code supporting "Pathway-tunable interfaces optimally attenuate droplet-impact stress waves" are publicly available. Files include:

1. DIC data. Displacement vector fields and strain fields extracted from all DIC experiments (`.mat`), together with the processing script `process.m`. Raw high-speed-camera images (`.bmp`) are provided for the representative case with $\lambda/\mathrm{FWHM} = 2.33$ and $A/H = 0.4$.

2. Pressure data. Raw pressure-sensor array data (`.xlsx`). Each `.xlsx` file contains multiple sheets, with each sheet corresponding to an independent experiment. Each sheet contains 15–40 pressure sampling distribution matrices, sorted in descending order of peak stress, collected from 15–20 droplet impact events in that experiment.

3. FEM files. Mesh input files (`.inp`), parameter files (`.prm`), and finite-element source code (`.cc` and `.h`).

4. Analysis scripts. Jupyter notebooks (`.ipynb`) used to generate the main figures and perform the statistical analyses.

5. Figure data. Source data underlying all figures presented in the main text and Supplementary Materials (`.xlsx`).
